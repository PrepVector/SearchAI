# Research memory

Standing project knowledge distilled from your own past feedback — this is
**not model training**; it's the same idea as a human research assistant
remembering "you like IEEE citations" after being told once. Every
`/run-research` call folds the directives below into the research-planner,
outline-architect, research-writer, and repair-editor agents' context.

Feedback can be given without being remembered ("do not remember this
run") — see `/run-research`'s periodic feedback prompt and
`feedback_log.md` for the raw history this gets distilled from.

Sensitive/private content is never stored here — only short feedback text
you typed yourself, never the contents of any document you researched.
