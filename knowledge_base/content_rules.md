# Content rules

Standing rules about how the report itself should read — read by
outline-architect, research-writer, and repair-editor. This is a
**research and professional content-generation** tool: rules here should
be about report quality (structure, tone, rigor), never about social-media
mechanics (hooks, scheduling, engagement) — that's explicitly out of scope
for SEARCH AI.

## Formatting preferences
- Always use markdown tables for comparisons instead of prose (3+ options
  or data points).
- Prefer bullet-point takeaways over paragraph summaries, at the section
  and report level.
